# 一图多用视觉资产提示词模板 v1.7

## 定位

v1.7 将视觉复用从“极简执行提示词”调整为“精准提取 + 结构化执行提示词”。

插件内部仍保留完整分析，供全览页检查；首页文本框和生图 API 只使用可直接生图的结构化执行版。

## 核心原则

视觉复用不是随机吸收灵感，而是在用户指定标签范围内精准继承对应特质。

- 用户指定标签：决定提取什么。
- 复用强度：决定保留多少。
- 补充要求：决定改哪里。
- 手动标签默认高强度继承。
- 自动判断标签默认中强度继承。
- 装饰参考只能作为辅助元素，不能成为主体。

## 首页与 API 输出

首页文本框和生图 API 固定输出 12 项：

1. 画面类型
2. 主体
3. 动作姿态
4. 构图
5. 排版文字
6. 色彩光照
7. 材质质感
8. 风格
9. 装饰
10. 继承要求
11. 变化要求
12. 避免

每项只写一段精炼内容，不输出图 1 / 图 2 过程说明，不输出 Role Check / Self Check，不输出冗余推理。

## 全览页输出

全览页可以展示更完整的检查信息：

- Chinese Prompt
- English Prompt
- Prompt Structure
- Role Check
- Self Check

这些信息用于检查继承逻辑，不直接作为生图 API 的最终输入。

## 长度建议

- 单图任务：300 到 500 中文字。
- 2 到 3 图复用：500 到 900 中文字。
- 复杂商业海报：900 到 1200 中文字以内。

## 长任务处理

RunningHub / APIMart 任务在本轮轮询结束仍未完成时，不再当作失败删除。

插件会保留任务 ID 和生成占位卡片，继续定时查询。若侧栏被关闭，Chrome 可能暂停前端脚本；下次打开插件后会自动恢复查询并回填图库。
