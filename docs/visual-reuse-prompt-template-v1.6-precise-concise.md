# Visual Reuse Prompt Template v1.6

Precise Reuse & Concise Execution Edition

## 核心目标

视觉复用分成两层输出：

- 首页文本框和生图 API 只使用极简执行提示词。
- 全览视图保留完整结构、角色检查和自检信息，方便排查复用逻辑。

## 执行提示词规则

`Chinese Prompt` 和 `English Prompt` 必须是可以直接生图的执行提示词，不写分析标签、不写长列表、不逐图解释。中文通常控制在 150-350 字，复杂场景最多不超过 500 字。

提示词只保留会影响生成结果的内容：主体、构图、排版、文字、色彩、质感、风格、装饰和明确变化点。

## 精准继承规则

用户手动给图片添加标签时，默认按高强度继承。没有手动标签时，系统可以自动判断参考范围，默认按中强度处理。

主体参考拥有最终主体所有权。没有主体标签的图片不能引入自己的主要人物、产品、车辆、角色、物体、场景或故事，只能贡献它被标注的维度。

补充要求是变化开关。用户没有要求变化的内容，应按标签和强度继承；用户明确要求变化时，变化优先级高于参考图。

## 全览输出结构

模型必须返回以下固定区块：

- `Chinese Prompt`
- `English Prompt`
- `Prompt Structure`
- `Role Check`
- `Self Check`

首页只展示 `Chinese Prompt`。全览视图展示所有区块。

## 生成尺寸规则

用户在界面选择的尺寸和比例优先级最高。提示词或参考图里任何冲突的横版、竖版、海报比例、画中画或留黑边要求，都必须被当前界面尺寸覆盖。
