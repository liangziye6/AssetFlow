# 视觉复用提示词模板 v1.5.1：精准继承版

## 核心定义

视觉复用不是随机提取视觉 DNA 后重新设计，而是在用户指定的标签范围内默认精准继承。

- 用户指定什么，就默认继承什么。
- 用户没有要求改变，就不要主动改变。
- 强度越高，越接近参考图。
- 补充要求是变化开关。
- 多图融合不是随机混合，而是按标签拼合不同特质。

## 默认强度

- 手动设置标签：默认高强度，默认锁定。
- 系统自动判断：默认中强度，不把自动判断当成强继承。
- 装饰参考无论强度如何，都只能作为辅助，不能成为主体。

## 复用模式

### 精准继承

默认模式。用户指定的每个标签范围内尽量保持原图一致，适合做系列图、风格延展和稳定复刻视觉结构。

### 平衡复用

保留核心特质，但允许模型适度整理和优化，适合商业视觉方向探索。

### 创意改写

只借鉴参考图的主要视觉语言，允许明显变化，适合寻找新方向。

## 标签规则

### 主体所有权

只要存在被标记为“主体参考”的图片，最终画面的主主体必须来自这些图片。没有“主体参考”标签的图片，即使画面里有人物、产品、车辆、IP、场景或其他显眼对象，也不能把这些内容带入最终主体，只能贡献它被选择的标签范围。

例如一张图只被标记为“色彩质感参考”，它只能贡献配色、光影、材质、纹理和氛围；图中的主体、产品、车辆、人物或场景都不能成为最终主体，除非这张图同时被标记为“主体参考”。

### 主体参考

高强度时保留主体类型、动作、姿态、服饰结构、发型轮廓、身体角度、表情气质、手势、道具、主体比例和镜头关系。

### 构图参考

高强度时保留画面框架、主体位置、主体占比、视觉中心、留白方向、镜头角度、空间层次和构图骨架。

### 排版参考

高强度时保留标题区域、标题比例、文字层级、文字方向、信息区、间距节奏和图文关系。除非用户选择无文字，否则不要主动去掉或弱化标题区。

### 字体参考

高强度时保留字体气质、字重、宽窄、压缩感、标题比例、变形方式、文字冲击力、材质感和与主体的关系。不要复制原文字内容，除非用户明确要求。

### 色彩质感参考

高强度时保留主色调、辅助色、色彩比例、对比度、饱和度、明暗关系、光影方向、高光方式、阴影方式、纹理、颗粒感、材质和整体氛围。

### 风格参考

高强度时保留整体审美、商业成熟度、艺术方向、渲染风格、视觉语言和设计质感。

### 装饰参考

高强度时保留装饰类型、线条语言、光轨、粒子、几何点缀、装饰密度和装饰与主体关系。装饰永远不能成为主体，不能主导构图，不能抢走视觉中心。

### 辅助参考

用于小道具、局部细节和次级视觉元素。辅助参考不能覆盖主体、构图、排版、字体、色彩或风格参考。

## 变化来源

最终提示词中的变化只能来自：

1. 用户补充要求。
2. 中强度或低强度复用设置。
3. 多张参考图角色冲突。
4. 不适合直接复制的元素，例如 Logo、商标、水印、真实人物身份、受保护角色身份、原图完整文案或私有 UI 信息。
