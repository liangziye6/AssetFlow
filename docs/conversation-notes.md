# Chrome 插件 - 提示词插件项目记录

更新时间：2026-05-12

## 项目目标

做一个 Chrome / Edge 提示词插件，用于从网页或本地收集图片，反推文生图提示词，配置生图模型与尺寸，并通过 API 生成图片。

核心使用场景：

- 在网页浏览时，把页面里的图片拖入插件。
- 用视觉模型反推提示词。
- 对提示词做中英转译、清空、继续编辑。
- 选择生图模型、尺寸、数量后生成图片。
- 已生成图片进入本地图库，支持查看、保存和后续整理。

## 当前产品形态

- 插件图标优先打开 Chrome Side Panel，位置在浏览器右侧，更接近插件下拉/侧栏体验。
- Side Panel 没有 Windows 系统标题栏，视觉比独立窗口更统一。
- 页面布局会根据宽度自适应：宽屏双栏，窄侧栏自动单列。
- API 面板和主操作区都采用深色玻璃拟态视觉。

## 已完成需求

- 支持最多 4 张图片上传/拖入。
- 多图会显示在统一尺寸的缩略图列表中。
- 每张上传图片都有删除按钮。
- 点击单张图片表示只处理该图。
- `Ctrl` / `Shift` 点击可多选，多选后反推提示词会批量处理，并用分割线区分每张图片结果。
- 支持获取原图尺寸、自定义尺寸，以及 `2K 1920 x 1080`、`4K 3840 x 2160`。
- 生图数量默认 1 张。
- 生图模型包含：
  - GPT Image
  - Flux Pro
  - SDXL
  - Midjourney
  - 即梦-Doubao-Seedream-4.0
  - 即梦-Doubao-Seedream-4.5
- 反推提示词 API 与生图 API 分开配置。
- 反推提示词已接入 Google Gemini 调用逻辑。
- 即梦生图按火山引擎 / Ark 图片生成接口格式设置。
- 中英转译按钮已实际生效；无 API 时会使用本地轻量转译。
- 反推提示词没有本地兜底，未配置 API 时文本框保持空白。
- 生成队列已合并到“已生成”图库中，生成中显示占位，完成后显示图片。
- 图库图片支持单击放大，右上角保留“收集到 Eagle”按钮。
- IP 形象曾尝试加入，后续暂时隐藏，等待更合适的透明素材或 3D 方案。

## 固定反推模板

反推提示词 API 内嵌模板：

```text
根据上传图片进行分析，并生成一个能够指导AI作图工具重新创作类似作品的文生图提示词。
提示词需含以下信息:主体内容、场景设定、风格参考、色彩色调、构图视角、附加细节。
请直接输出最终提示词，不要解释分析过程。
```

## API 设计

### 反推提示词 API

用途：看图理解，输出可用于文生图的提示词。

当前支持：

- OpenAI-compatible 视觉模型
- Google Gemini
- SiliconFlow
- 自定义 Base URL

Gemini 默认：

- Base URL: `https://generativelanguage.googleapis.com/v1beta`
- 模型：`gemini-2.5-flash` 或 `gemini-2.5-pro`
- 调用：`/models/{model}:generateContent`
- 鉴权：`x-goog-api-key`

### 生图 API

用途：提交提示词、尺寸、数量并返回图片。

当前支持：

- OpenAI-compatible 图片生成接口
- 即梦 / Doubao Seedream 4.0、4.5
- SiliconFlow
- Replicate 占位
- ComfyUI 本地占位
- 自定义 Base URL

即梦接口参考：

- Base URL: `https://ark.cn-beijing.volces.com/api/v3`
- 路径：`/images/generations`
- 模型：
  - `doubao-seedream-4-0-250828`
  - `doubao-seedream-4-5-251128`
- 2K 尺寸传 `2K`
- 4K 尺寸传 `4K`

## 浏览器限制说明

- Chrome 扩展的小弹窗尺寸由浏览器控制，不能自由拖拽改变大小。
- 小弹窗失焦后容易关闭，不适合从网页直接拖图。
- 独立 Windows 弹窗可以调整大小，但会带系统标题栏，也不能真正系统级置顶。
- 当前最佳方案是 Chrome Side Panel：位于浏览器右侧，可调整宽度，适合网页拖图和长期使用。
